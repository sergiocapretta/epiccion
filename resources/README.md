Questa cartella contiene le risorse utilizzate dagli strumenti
di sviluppo di E-Piccion.

Per generare EmojiAlphabet.php è necessario scaricare
il file ufficiale Unicode:

emoji-test.txt

e copiarlo in questa cartella.

Il file è disponibile qui:

https://www.unicode.org/Public/emoji/latest/emoji-test.txt

Successivamente eseguire:

php tools/generateAlphabet.php
